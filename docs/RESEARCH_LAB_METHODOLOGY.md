# Research Lab — methodology and metric provenance

> Source data, code, saved models and all output tables/figures live in [`research/`](../research/README.md), which also records which numbers in this app were checked against them.

## Purpose

The Research Lab embeds the AgriSense drought-hardening/root-response data-science demo in the existing AgriSense app. It is a research/education surface, not an agricultural decision-support endpoint.

## Variables and targets

Inputs:
- Soil rigidity (kPa)
- Hydrogel concentration (%; basis not specified in the synthetic schema)
- Average daily rainfall (mm/day)

Targets:
- Root elongation rate (mm/day), generated by the scenario equation plus noise
- EXPA1-like stress-response fold-change proxy, generated by the scenario equation plus noise

The proxy is not actual gene-expression data. The unit basis of the hydrogel percentage is not specified and should not be described as w/w or w/v unless the experiment definition is changed.

## Phase 1 — quality control

The audited generated dataset contains 1,000 rows and six columns. The source quality report records zero missing values, zero duplicate Trial_ID values, zero exact duplicate rows, zero numeric-conversion failures, zero allowed-range violations, and zero integrity-rule row removals. Tukey IQR checks generated feature-level outlier flags; these values were retained for review and not automatically removed. Outlier flag entries may overlap on the same observation.

## Phase 2 — exploratory analysis

The chart displays Pearson correlations from the generated dataset. In that dataset:

- Rainfall and root elongation: r = 0.63749
- Hydrogel and root elongation: r = 0.58478
- Hydrogel and the EXPA1-like proxy: r = -0.54927
- Soil rigidity and the proxy: r = 0.73740

These associations reflect the data generator's assumptions, feature correlations, and random noise. They are not independently estimated biological effects. In particular, rainfall and soil rigidity are correlated in the generated records, so their individual correlations should not be interpreted as separate causal contributions.

## Phase 3 — model comparison and selection

Model comparison considers a mean baseline, linear regression, degree-2 polynomial features plus linear regression (labeled “Linear + interactions”), Random Forest, and Gradient Boosting.

Selection was based on repeated 5-fold cross-validation with 3 repeats on the training partition (800 rows); the separate 200-row holdout was reserved for evaluation. Mean CV RMSE was used for model selection.

| Target | Selected model | Mean CV R² | Mean CV MAE | Mean CV RMSE |
|---|---|---:|---:|---:|
| Synthetic root elongation | Linear + interactions | 0.87284 | 0.58445 | 0.72872 |
| EXPA1-like synthetic proxy | Linear + interactions | 0.83689 | 0.25184 | 0.31642 |

Scores describe how well models reconstruct the programmed synthetic targets. They do not show that the model can predict real crop measurements. The original model report retains each candidate's holdout metrics; do not substitute the selected model's cross-validation score for a holdout score.

## Phase 4 — supplemental analysis

The supplied advanced analysis uses an additional repeated 5-fold CV with 5 repeats across the full generated dataset, alongside residual diagnostics, correlation heatmaps, permutation importance, sensitivity and dose-response analyses, conformal interval calibration, VIF checks, and a high-rigidity distribution-shift test.

This supplemental CV design is **not the same** as the Phase 3 training-only model-selection design. Results must remain labeled separately. For example, the supplemental interval exercise reported an empirical 90.8% coverage on 250 synthetic test rows with an approximately ±1.27 mm/day half-width. This is a demonstration of interval calibration on synthetic data, not an uncertainty guarantee for live crops or a calibrated interval for every point on the UI's scenario sliders.

## Scenario predictions in the app

`src/data/agrisense-research.ts` mirrors the degree-2 polynomial-feature + linear-regression coefficients exported from the selected model pipelines. The browser calculates predictions locally so the Netlify app does not require the separately hosted FastAPI service simply to demonstrate the scenario explorer.

The displayed predictions are clamped to the target ranges used in the synthetic generator. The UI reports when any feature lies outside the minimum/maximum observed in training (soil rigidity 5–69.64 kPa; hydrogel 0–2%; rainfall 0.04–12 mm/day). A value within the allowed slider limits can still be outside observed training range. Clamping is a display safety guard and must not be described as model confidence or validation.

**Coefficient maintenance:** if the data-generation formula, feature order, training script, selected pipeline, or saved model artifacts change, update the coefficients and observed ranges in `src/data/agrisense-research.ts`, verify representative predictions against the saved Python pipelines, and rerun the website's build and typecheck before deployment.

## Reproducibility and limitations

- Track the data-generation seed and document any changes to the equations.
- Keep raw, cleaned, model-selection, and supplemental-analysis outputs identifiable and separate.
- Do not state that the analysis proves hydrogels improve root growth or determines an optimal real-world dose.
- Do not call the proxy “measured EXPA1 expression”; use “EXPA1-like synthetic proxy.”
- Real conclusions require validated methods, actual plant/soil measurements, experimental controls, and external validation.
