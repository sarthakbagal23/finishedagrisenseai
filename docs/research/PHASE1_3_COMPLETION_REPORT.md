# AgriSense AI — Phase 1–3 Completion Report

**Report refresh:** October 13, 2026  
**Scope:** Phase 1 data quality; Phase 2 statistics; Phase 3 candidate comparison, model selection, holdout evaluation, and API artifacts.  
**Data status:** synthetic scenario data only. No rows are measured plant trials, soil-instrument readings, weather observations, or laboratory gene-expression assays.

## Executive summary

The package now has a reproducible path from data generation to an interactive website:

1. Generate and audit 1,000 synthetic rows.
2. Run statistical summaries and generate descriptive plots/findings.
3. Compare five regression candidates using training-only repeated cross-validation, then report an untouched 20% holdout comparison.
4. Save the selected models for the FastAPI prediction endpoint.
5. Run the advanced analysis script and synchronize its eight figures into the `/research` page.

The current pipeline selects degree-2 interaction regression for both targets. That selection is appropriate for this **formula-generated demo**; it does not establish that the model is best for real plant data.

### Data meaning and units

- Hydrogel is named in percent, but the concentration basis is not defined. Do not relabel as % w/w or % w/v without specifying that in the protocol.
- Soil rigidity uses an illustrative kPa input scale, not a validated or calibrated soil test method.
- Rainfall is a synthetic scenario variable, not sourced local weather data.
- Root elongation is the generated target, not observed plant growth.
- `Stress_Gene_Expression_Fold_Change` is a hypothetical EXPA1-like proxy, not an actual transcriptomic assay.

## Phase 3 — Model comparison and API

### Design

The model candidates are:

- Training-mean baseline
- Plain linear regression
- Linear regression with degree-2 polynomial features (main effects, squared terms, and pairwise interactions)
- Random Forest regression
- Gradient Boosting regression

A fixed shuffled 80/20 split (`random_state=42`) provides 800 training rows and 200 holdout rows. The winning model is selected by lowest mean RMSE across five-fold cross-validation repeated three times on the 800-row training partition only. That avoids using the holdout labels to choose the model. The untouched 200-row partition is then used for the reported comparison metrics. After evaluation, the selected model is refit on all 1,000 synthetic rows for the local demo API.

Cross-validation on training rows selected `linear_interactions` for both targets because its mean CV RMSE was lowest among the five candidates. Other model families and their metrics are recorded in `outputs/model_comparison_report.md`, `outputs/model_metrics.json`, and `outputs/cross_validation_metrics.csv`.

### Saved API artifacts

- `models/root_elongation_model.joblib` — degree-2 polynomial feature + linear regression pipeline.
- `models/stress_gene_proxy_model.joblib` — degree-2 polynomial feature + linear regression pipeline.
- Candidate-specific artifacts are also saved for comparison.

The API clips display values to the synthetic target ranges and reports when clipping occurs. Illustrative LOW/MODERATE/HIGH display bands are not validated biological thresholds.

## Final limitation

Because the outcomes are generated from equations selected for this project, even strong correlations and high model scores primarily measure reconstruction of the synthetic scenario. They are not evidence of actual hydrogel treatment effects, crop yield changes, EXPA1 expression, or reliable field predictions. Do not use these outputs to make agricultural decisions.
